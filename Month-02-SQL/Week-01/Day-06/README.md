# SQL Day 06 — Revision & Business Practice

## Date
10 October 2026

## Objective
Revise fundamental SQL concepts and apply them to practical customer-data analysis questions using MySQL.

## Topics Covered
- SELECT and WHERE
- Comparison operators
- AND, OR, and NOT
- IN and BETWEEN
- LIKE and pattern matching
- IS NULL and IS NOT NULL
- ORDER BY with ASC and DESC
- LIMIT
- Combining multiple filtering and sorting conditions

## Practice
Completed 10 revision and business-oriented SQL questions using the customers table.

## Key Learnings
- Filter records using one or multiple conditions.
- Use IN to check multiple possible values.
- Use BETWEEN to filter inclusive ranges.
- Use LIKE to search for text patterns.
- Handle missing values using IS NULL and IS NOT NULL.
- Sort records and retrieve the highest or lowest results using ORDER BY and LIMIT.
- Combine SQL clauses to answer business questions.

MySQL

# SQL Day 07 — E-commerce Sales Analysis Project

## Project Overview
This project uses MySQL to analyze customer information and e-commerce orders through practical business questions.

## Database
- Database: `data_analyst`
- `ecom_customers`: Customer details
- `ecom_orders`: Order date, category, amount, payment method, and status

## Dataset
- 12 customer records
- 20 order records

## SQL Concepts Practiced
- SELECT and WHERE
- Comparison operators
- AND and OR
- IN and BETWEEN
- NULL handling
- ORDER BY and LIMIT
- Combining filtering and sorting conditions

## Business Questions
1. Display all customers.
2. Find customers from Delhi.
3. Find female customers aged 25 or above.
4. Identify customers with missing city values.
5. Find orders between ₹20,000 and ₹50,000.
6. Identify cancelled orders.
7. Sort orders by amount.
8. Find the top five highest-value orders.
9. Filter high-value UPI orders.
10. Analyze Electronics orders.
11. Find high-value delivered orders.
12. Find the top three pending orders.

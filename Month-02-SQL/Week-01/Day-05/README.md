# SQL Day 05 — ORDER BY & LIMIT

## Date

09 October 2026

## Objective

Learn how to sort query results and retrieve a limited number of records using MySQL.

## Topics Covered

* ORDER BY clause
* ASC — Ascending order
* DESC — Descending order
* Sorting by multiple columns
* LIMIT clause
* Combining WHERE, ORDER BY, and LIMIT
* Business-oriented data filtering and ranking

## Practice Completed

Solved 12 SQL practice questions independently without using hints.

Practice tasks included:

* Sorting customers by age and total spending
* Finding the top 3 highest-spending customers
* Finding the 5 youngest customers
* Identifying top-spending customers in specific cities
* Combining WHERE filters with sorting and LIMIT
* Sorting by multiple columns

## Key Learnings

* ASC sorts values from low to high.
* DESC sorts values from high to low.
* ORDER BY can sort results using multiple columns.
* LIMIT restricts the number of rows returned.
* Combining WHERE, ORDER BY, and LIMIT helps answer practical business questions.

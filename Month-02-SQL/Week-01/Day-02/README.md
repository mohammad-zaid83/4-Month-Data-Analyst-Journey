# SQL Day 02 — SELECT, FROM & WHERE

## Date
03 October 2026

## Objective

The goal of Day 2 was to learn how to retrieve and filter data from a MySQL table using basic SQL queries.

## Topics Covered

- SELECT
- SELECT *
- Selecting specific columns
- FROM
- WHERE
- Comparison operators
- Text filtering
- Numeric filtering
- Business-based filtering

## Comparison Operators Practiced

- =  Equal to
- >  Greater than
- <  Less than
- >= Greater than or equal to
- <= Less than or equal to
- <> Not equal to

## Key SQL Structure

SELECT columns
FROM table
WHERE condition;

## Practice

Solved business-oriented questions using the customers table, including:

- Filtering customers by city
- Filtering customers by gender
- Filtering customers by age
- Filtering customers by total spending
- Selecting only required columns
- Combining SELECT and WHERE

## Key Learning

SQL filtering follows a simple thought process:

What data do I need? → SELECT

Where is the data? → FROM

What condition should it satisfy? → WHERE

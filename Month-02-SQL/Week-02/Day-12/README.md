# SQL Day 12 — Business Analysis Practice

## Overview
Practiced business-oriented data analysis queries using MySQL and the `ecom_orders` table.

## Topics Covered
- Aggregate functions: `COUNT()`, `SUM()`, `AVG()`, `MAX()`
- `WHERE` for filtering rows
- `GROUP BY` for category-wise and payment-method analysis
- `HAVING` for filtering aggregated results
- `ORDER BY` for sorting results
- Combining multiple SQL clauses to solve business problems

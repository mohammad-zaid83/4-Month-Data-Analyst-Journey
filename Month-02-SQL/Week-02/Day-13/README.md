# SQL Day 13 — Introduction to JOINs

## Overview
Learned and practised SQL JOINs using MySQL and the e-commerce database.

## Topics Covered
- INNER JOIN
- LEFT JOIN
- ON clause
- Table aliases
- Primary key and foreign key relationships
- Combining JOINs with WHERE
- JOINs with aggregate functions
- GROUP BY and ORDER BY

## Tables Used
- `ecom_customers`
- `ecom_orders`

## Practice Questions
1. Customer Orders
2. Customer City Analysis
3. All Customers
4. High-Value Orders
5. Delivered Orders
6. Payment Method Analysis
7. Customers Without Orders
8. Customer-wise Order Analysis

## Key Learnings
- Combined customer and order data using JOINs.
- Identified unmatched records using LEFT JOIN and IS NULL.
- Used COUNT() and SUM() for customer-wise analysis.
- Applied GROUP BY to generate customer-level summaries.
- Sorted results using ORDER BY.

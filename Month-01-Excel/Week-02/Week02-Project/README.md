# Week 02 — Final Excel Project

## Project: Customer & Sales Data Cleaning + Analysis

## Objective

Clean customer data, connect sales data with product information, calculate sales and extract useful business insights.

## Skills Used

- TRIM
- Text Cleaning
- Duplicate Detection
- COUNTIF / COUNTIFS
- IF / IFS
- Data Validation
- XLOOKUP
- VLOOKUP
- UNIQUE
- FILTER
- SORT
- Basic calculations

## Project Workflow

Raw Data
→ Cleaning
→ Duplicate Detection
→ Lookup
→ Calculation
→ Filtering
→ Analysis

## Key Tasks

- Cleaned customer information
- Identified duplicate customers
- Added product information using lookup functions
- Calculated total sales
- Performed category and sales analysis
- Used dynamic filtering for business questions
- Created management insights

## Key Learning

This project helped me understand how Excel functions can be combined to solve practical data-analysis problems rather than being used individually.

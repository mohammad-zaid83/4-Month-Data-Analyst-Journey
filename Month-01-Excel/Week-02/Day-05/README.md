# Week 02 — Day 05: Lookup Functions

## Overview

Day 05 focused on using lookup functions to connect information from different Excel tables.

## Topics Learned

- XLOOKUP
- VLOOKUP
- Exact Match
- Lookup between tables
- Lookup + calculations
- COUNTIF / SUMIF with lookup results
- Business analysis using lookup functions

## Practical Work

Worked with Sales Data and a Product Master table.

Automatically retrieved:

- Product Name
- Category
- Unit Price

Then calculated Total Sales and answered business questions.

## Key Learning

Lookup functions allow information from different tables to be connected using a common key such as Product ID.

## Analyst Workflow

Key → Lookup → Required Information → Calculation → Analysis

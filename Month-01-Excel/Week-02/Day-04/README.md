# Week 02 — Day 04: Dynamic Data Analysis

## Overview

Day 04 focused on extracting and organizing data dynamically using Excel.

## Topics Learned

- UNIQUE
- SORT
- FILTER
- Multiple-condition filtering
- Dynamic data extraction
- AND conditions using FILTER

## Practical Work

Worked with an employee dataset to:

- Find unique departments
- Find unique cities
- Sort employees by salary
- Filter employees by department
- Filter employees by performance
- Filter employees by city
- Apply multiple conditions
- Extract employees based on salary criteria

## Key Learning

Learned how FILTER can be used to answer business questions by applying multiple conditions to a dataset.

Business Question → Conditions → Filter → Result

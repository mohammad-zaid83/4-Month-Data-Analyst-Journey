## 🛠️ Practical Work

Created an interactive Sales Performance Dashboard
using Excel.

The dashboard contains:

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Sales KPI
- City-wise Sales Chart
- Monthly Sales Trend
- Category-wise Performance
- City and Category Slicers
- Business Insights

## 📊 Dashboard Analysis

The dashboard was designed to provide a quick overview
of sales performance and allow data to be filtered
interactively.

## 💡 Key Learning

A dashboard combines data summaries, KPIs,
visualizations and business insights into a single
interactive report.

The main workflow practiced was:

Raw Data
→ Summary
→ KPI
→ Visualization
→ Filtering
→ Business Insight
→ Dashboard

## 🎯 Data Analyst Perspective

The objective of a dashboard is not only to make
data visually attractive, but to make important
business information easier and faster to understand.

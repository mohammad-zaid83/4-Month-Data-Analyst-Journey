# Week 04 - Day 05: XLOOKUP & Dynamic Lookup Analysis

## 📌 Topics Covered

- XLOOKUP
- Dynamic Lookups
- Product ID Mapping
- Error Handling
- XLOOKUP vs VLOOKUP
- Category Analysis
- Product Performance Analysis
- Connecting Related Datasets

## 🛠️ Practical Work

Worked with Sales Data and a Product Master
dataset connected through Product_ID.

Used XLOOKUP to automatically retrieve:

- Product Name
- Category
- Unit Price

Also calculated Total Sales and performed
category-wise and product-wise analysis.

## 🔎 Error Handling

Tested an invalid Product_ID and handled
the lookup error using a custom message:

"Product Not Found"

## 💡 Key Learning

A lookup function can connect two related
datasets using a common key.

Sales Data
→ Product_ID
→ Product Master
→ Product Information
→ Analysis

## 📊 Business Application

A dynamic lookup tool was created where changing
the Product_ID automatically updates the related
product information.

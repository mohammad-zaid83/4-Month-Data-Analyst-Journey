# Week 03 - Sales Performance & Interactive Analysis Project

## 📌 Project Overview

Built a complete Excel sales analysis project using a
sample business sales dataset.

The project focuses on analyzing sales performance,
identifying patterns and creating an interactive report.

## 🛠️ Excel Skills Used

- IF
- YEAR
- TEXT
- SUM
- COUNTA
- AVERAGE
- PivotTables
- Conditional Formatting
- Slicers
- KPI Analysis
- Business Insights

## 📊 Analysis Performed

- City-wise Sales & Quantity
- Category-wise Sales & Quantity
- Salesperson Performance
- City × Category Analysis
- Order Analysis
- Error Analysis
- Interactive filtering using Slicers

## 📈 Dashboard

Created a clean and readable Sales Performance Dashboard
with KPIs, PivotTable analysis and interactive Slicers.

## 💡 Business Insights

Analyzed the data to identify:
- Highest-performing cities
- Top-performing categories
- Salesperson performance
- Quantity patterns
- Error patterns
- City and category combinations

## 📁 Workbook Structure

- `01_Raw_Data` — Original dataset
- `02_Calculations` — Formulas and KPIs
- `03_Pivot_Analysis` — PivotTable analysis
- `04_Dashboard` — Interactive dashboard
- `05_Insights` — Business observations

## 🎯 Key Learning

This project helped me practice the complete process:

Raw Data → Calculations → PivotTables → Visualization
→ Interactive Analysis → Business Insights

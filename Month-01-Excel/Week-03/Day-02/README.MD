# Week 03 — Day 02: Date & Time Analysis

## Overview

Day 02 focused on working with dates and performing time-based analysis in Excel.

## Topics Learned

- TODAY()
- YEAR()
- MONTH()
- DAY()
- TEXT()
- DATEDIF()
- DATE()
- Date-based SUMIFS
- Date-based COUNTIFS
- Date ranges
- FILTER with multiple conditions

## Practical Work

Worked with sales data to:

- Extract year, month and day
- Calculate date differences
- Analyze sales by month
- Count orders based on date conditions
- Apply date ranges
- Filter records using multiple conditions

## Key Learning

Learned how Excel dates can be used as conditions for calculations and business analysis.

## Important Concept

For date-range analysis:

Start Date <= Date < Next Period Start Date

This makes date-based analysis more reliable.

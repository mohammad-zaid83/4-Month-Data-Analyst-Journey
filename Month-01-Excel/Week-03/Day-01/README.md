# Week 03 — Day 01: Multi-Condition Analysis

## Overview

Day 01 focused on analyzing data using multiple conditions in Excel.

## Topics Learned

- SUMIFS
- COUNTIFS
- AVERAGEIFS
- Multiple conditions
- AND-based analysis
- Business-question driven formulas

## Practical Work

Worked with employee sales data and answered business questions involving:

- Total sales
- Employee counts
- Average sales
- Department-based analysis
- City-based analysis
- Department + City combinations
- Department + Rating combinations

## Key Learning

Learned how to convert business questions into Excel conditions and select the appropriate IFS function.

### Formula Selection

- SUMIFS → Multiple conditions + Total
- COUNTIFS → Multiple conditions + Count
- AVERAGEIFS → Multiple conditions + Average

## Analyst Thinking

Business Question  
→ Identify Conditions  
→ Select Function  
→ Calculate  
→ Interpret Result

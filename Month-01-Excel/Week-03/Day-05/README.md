- Duplicate Values

## 🛠️ Practical Work

Used Conditional Formatting to identify:

- High and low sales
- Employees with errors
- High performers
- Duplicate values
- Important data patterns
- Multiple-condition exceptions

Also created custom formatting rules using formulas.

## 💡 Key Learning

Conditional Formatting helps analysts quickly identify
patterns, exceptions and performance differences in data.

The analysis process:

Data → Visual Pattern → Observation → Business Insight

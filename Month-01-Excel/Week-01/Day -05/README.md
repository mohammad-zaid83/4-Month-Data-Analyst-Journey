# Day 05 — Conditional Aggregation in Excel

## Overview

Day 05 focused on conditional aggregation functions in Excel and their practical use in data analysis.

A sales dataset containing regions, categories, sales, profit and quantities was used to solve business-oriented questions.

## Topics Learned

- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- AVERAGEIF
- AVERAGEIFS
- Single-condition analysis
- Multi-condition analysis
- Numeric criteria
- Business-oriented aggregation

## Practical Work

Analyzed a 20-record sales dataset and calculated:

- Total sales by region
- Total profit by region
- Total sales by category
- Order counts by region and category
- Sales using multiple conditions
- Profit using multiple conditions
- Average sales
- Average profit
- Sales and profit based on numeric criteria
- Regional sales comparison
- Category-wise profit comparison

## Key Learning

Learned how to translate business questions into Excel aggregation formulas.

For example:

Business Question:
"How much did the North region generate from Electronics?"

Logic:

Region = North
AND
Category = Electronics
Calculation = Total Sales

This requires a multi-condition aggregation using SUMIFS.

## Analyst Thinking

The main focus was not memorizing formulas.

The focus was:

Business Question → Conditions → Function → Formula → Result

I also explored how to compare multiple regions and categories instead of manually calculating every result.

## Important Observation

For a small number of categories, individual calculations can work.

For larger datasets with many categories or regions, scalable tools such as PivotTables and dynamic Excel techniques become more useful.

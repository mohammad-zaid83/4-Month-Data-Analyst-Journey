# Day 04 — Excel Revision & Practical Analysis

## Overview

Day 04 focused on revising the Excel concepts learned during the first three days and applying them to a practical employee performance dataset.

The main objective was to solve business-style problems independently instead of following predefined formulas.

## Topics Practiced

* IF
* AND
* OR
* NOT
* IFS
* IFERROR
* Nested IF
* COUNTIF
* COUNTIFS
* Relative References
* Absolute References
* Percentage-based conditions
* Logical business conditions
* Filtering and result verification

## Practical Analysis

Created an employee performance dataset containing:

* Sales
* Target
* Attendance
* Errors
* Customer Rating
* Experience

Used Excel formulas to create:

* Target Status
* Performance Classification
* Risk Flag
* Quality Check
* Performance Grade
* Bonus Eligibility
* Promotion Eligibility
* Sales per Error
* Employee Category

## Business Analysis

The dataset was used to answer questions such as:

* Which employees achieved their targets?
* Which employees qualified for bonuses?
* Which employees were promotion candidates?
* Which employees required attention?
* How many employees satisfied multiple business conditions?

## Key Learning

The main learning from Day 04 was converting a business requirement into logical conditions and then implementing those conditions using Excel formulas.

The workflow practiced was:

Business Question → Logic → Formula → Result → Verification

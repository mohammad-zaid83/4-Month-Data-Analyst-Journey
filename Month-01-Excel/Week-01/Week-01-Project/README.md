# Week 01 — Sales Analysis Project

## Project Overview

This project was created as the Week 01 practical project of my 4-Month Data Analyst Journey.

The objective was to analyze a sales dataset using Excel and answer business-oriented questions using formulas and logical conditions.

## Dataset

The dataset contains 20 sales orders with the following fields:

- Order ID
- Region
- Category
- Sales
- Profit
- Quantity

## Excel Concepts Applied

- SUM
- AVERAGE
- COUNT
- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- AVERAGEIF
- AVERAGEIFS
- IF
- AND
- Logical conditions
- Filtering
- Business rule-based classification

## Analysis Performed

The project analyzed:

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Regional Sales
- Regional Profit
- Category Sales
- Category Profit
- Multi-condition analysis
- High Value Orders
- High Profit Orders
- Strong Orders

## Business Questions

The analysis answered questions such as:

- Which region generated the highest sales?
- Which category performed best?
- What is the average sales per order?
- How many high-value orders were generated?
- Which orders were both high-value and high-profit?

## Key Learning

The main objective was to convert business questions into Excel logic and formulas.

The workflow followed was:

Business Question → Logic → Formula → Result → Insight

## Project Structure

- `Raw_Data` — Original dataset
- `Analysis` — Calculations and business questions
- `Summary` — Final KPIs and insights

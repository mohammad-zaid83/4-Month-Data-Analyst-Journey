# Day 03 — Excel Logical Functions & Business Conditions

## Topics Learned

* IF
* AND
* OR
* NOT
* IFS
* IFERROR
* Nested IF
* Multiple-condition analysis
* Business rule-based analysis

## Practical Work

Worked on an employee sales-performance dataset and created:

* Target Status
* Performance Category
* Attention Flag
* Error Status
* Performance Grade
* Bonus Eligibility
* Promotion Eligibility
* Sales per Error
* Employee Category
* Target + Attendance analysis

## Key Learning

Today I learned how Excel logical functions can be used to convert business conditions into measurable results.

Instead of looking at data manually, I practiced building formulas that automatically classify employees based on sales, targets, attendance, errors and customer ratings.

## Analyst Thinking

The main focus was not just learning formulas, but understanding how logical conditions can be used for real business decision-making.

## Result

Completed all Day 03 exercises independently and practiced combining multiple conditions using IF, AND, OR, IFS, NOT and IFERROR.
